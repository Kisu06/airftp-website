# Air FTP Server — Official Website

The official, premium landing page for **Air FTP Server** for Android. Rebuilt using clean, flat Material 3 light mode to perfectly match the mobile application's authentic aesthetics.

🌐 **Live Website**: [https://kisu06.github.io/airftp-website/](https://kisu06.github.io/airftp-website/)

---

## 📱 Features

- **Interactive Android Simulator**: Full-fidelity responsive phone mockup simulating the app in **Stopped** and **Running** states, complete with dynamic card toggles and URL copy button.
- **Pure Material 3 Aesthetics**: Modeled exactly after the Android XML properties — pure white background (`#FFFFFF`), flat blue-gray cards (`#F3F5F9`), and vibrant Material Blue accents (`#2196F3`). No neon gradients or generic AI drop shadows.
- **Privacy Policy Page**: Built-in, fully compliant privacy policy meeting Google Play Developer policies.
- **Zero Dependencies**: Lightweight vanilla CSS/JS, custom inline SVG icons, and optimized asset loading.

## 🛠️ Customization & Hosting

This is a completely static website and is pre-configured to be hosted for free on **GitHub Pages**:
1. Push this code to the `main` branch.
2. Go to **Settings ➔ Pages** in your GitHub repository.
3. Set the source branch to `main` and folder to `/ (root)`.
4. Click **Save** and it will be live at `https://<your-username>.github.io/airftp-website/`!
