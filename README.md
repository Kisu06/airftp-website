## ⚡ The Modern Alternative to USB Cables

Say goodbye to slow transfers and tangled cables. **Air FTP Server** uses advanced network protocols to enable blazing-fast, secure file transfers on your local connection.

| Core Benefit | Description |
| :--- | :--- |
| 🚀 **Blazing-Fast Speed** | Built on top of the Apache FTP Server core for lightning-fast speeds over local WiFi. |
| 🔐 **Industrial Security** | Protect your authentication credentials and files with SSL/TLS encryption (FTPS). |
| 🛡️ **Absolute Privacy** | Zero tracking, zero ads, zero data collection. Everything runs entirely offline on your phone. |
| 🎨 **Material 3 Aesthetics** | Simple, beautiful, and fully customized light/dark interface native to Android 14+. |

## 🌟 Advanced Features

* 🚀 **Instant Toggle**: Start or stop your local FTP server with a single tap.
* 📂 **Custom Storage Roots**: Share specific directories or folders, keeping other files secure.
* 🔐 **Secure Logins**: Choose between secure credential-based login or optional anonymous access.
* ⚙️ **Developer Port Controls**: Configure custom port numbers ranging from `1024` to `65535` (Pro feature).
* 📊 **Live Dashboard**: View active client IPs, transfer speeds, and session metrics in real-time.

## 🛠️ Quick-Start Guide (3 Steps)

1. **Active WiFi Connection**: Ensure both your phone and computer are connected to the same local WiFi network.
2. **Launch & Start**: Open Air FTP Server and click the power button. The screen will show your FTP Address (e.g. `ftp://192.168.1.100:2221`).
3. **Connect & Transfer**: Open your preferred desktop client (FileZilla, WinSCP, or Windows File Explorer) and enter the FTP URL to start dragging and dropping files!
